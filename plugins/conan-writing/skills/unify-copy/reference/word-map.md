# 단어 바꿈 사전

짧은 문구나 설명 문장의 동사를 단어로 바꿀 때 쓰는 짝이다. 왼쪽 표현을 오른쪽 단어로 바꾼다. 처음 보는 사람이 바로 알아듣는 단어만 고른다.

## 행위

| 고유어·풀어 쓴 표현 | 단어 |
|---|---|
| 쓰기, 적어 넣기 | 작성 |
| 적기, 넣기, 채우기 | 입력 |
| 만들기 | 생성 (화면·문서), 제작 (콘텐츠) |
| 고르기 | 선택 |
| 읽기, 보기, 살펴보기 | 확인 |
| 보여 주기 | 표시 (화면에 띄움), 안내 (알려 줌) |
| 알려 주기 | 안내 |
| 고치기 | 수정 |
| 다듬기 | 보완 |
| 넘기기, 건네기 | 전달 |
| 이어 가기 | 연결 |
| 맞춰 보기, 견주기 | 대조 |
| 따져 보기 | 검토 |
| 모으기 | 수집 |
| 나누기 | 분리, 분담 (일) |
| 빼기 | 제외 |
| 남기기 | 기록 |
| 미리 정해 두기 | 사전 정의 |
| 물어보기 | 질문 |
| 답하기 | 응답 |
| 켜기 | 실행 |

## 대상·상태

| 풀어 쓴 표현 | 단어 |
|---|---|
| 걸리는 시간 | 소요 시간 |
| 아는 내용, 더 적는 내용 | 추가 정보 |
| 팀마다, 팀별로 만드는 | 팀별 |
| 같은 기준 | 공통 기준 |
| 앞 문서를 읽고 | 앞 문서 기반 |
| 처음부터 다시 | 새로 |
| 빠지는 것 | 누락 |
| 서로 다른 것 | 불일치 |
| 지금 어디인지 | 진행 단계 |

## 쓰지 않는 바꿈

- 뜻이 좁아지거나 넓어지는 바꿈은 하지 않는다. "보여 주기"는 화면에 띄우는 뜻이면 "표시", 사람에게 알려 주는 뜻이면 "안내"로 문맥에 따라 고른다.
- 업계 밖 사람이 모르는 한자어(예: 상신, 품의, 기안)는 문서가 그 업계 사람에게 가는 경우에만 쓴다.
